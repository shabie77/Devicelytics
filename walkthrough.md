## 🛡️ Security & Reliability Hardening

We have fixed the core vulnerabilities identified during the code review:

| Feature | Fix Implemented |
| :--- | :--- |
| **Silent Mocks (P1)** | **REMOVED.** The app now errors if real AI is unavailable, preventing "fake" analysis. |
| **Logging Blockers (P1)** | **DECOUPLED.** Supabase outages no longer prevent users from seeing AI results. |
| **Image Poisoning (P2)** | **HARDENED.** Added server-side MIME-type and size validation (2.5MB cap). |
| **QA Auth Leak (P3)** | **FIXED.** Logs now strictly require the secret in the Authorization header. |

## 🧠 AI "Digital Bodyguard" Logic

The AI has been upgraded with a skeptical technical appraiser persona:
- **Market Logic**: It now explicitly compares asking prices against depreciation models.
- **Detailed Evidence**: Reasoning is now multi-paragraph and covers condition, price, and fraud risk.
- **Verification Guidance**: It generates specific "Suggested Messages" for the seller to flush out scams.
